About Me

Dr Mesut İnan is a Cyber Security Researcher and Senior Lecturer working at the intersection of Cyber Security, Artificial Intelligence, Information Security and Computer Science.

His academic and technical interests include secure artificial intelligence, neural cryptography, offensive security, cloud security, secure software engineering and the responsible adoption of emerging technologies.

His work combines academic research, practical cybersecurity, software engineering and higher education teaching, with an emphasis on technically rigorous and real-world applicable solutions.

Research Projects

AEGIS-SENTINEL

Research project focused on civilian airspace threat detection and critical infrastructure protection.

The project explores sensor fusion, intelligent threat assessment and human-authorised decision making for safety-critical environments.

AFSS

Research project investigating secure and adaptive systems, optimisation and computational modelling.

The work explores optimisation-based approaches including PSO, GA and CMA-ES within security-oriented computational design.

Cyber Web Assessment Agent

Modular web security assessment framework designed to collect evidence, analyse security characteristics, evaluate risk and produce structured reports.

The architecture follows a test-driven development philosophy: Code → Test → PASS → Next Component.
