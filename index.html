About

Dr Mesut İnan is a Cyber Security researcher and Senior Lecturer working across Artificial Intelligence, Cybersecurity, Information Security and Computer Science.

Academic Profile

His academic and research interests focus on the intersection of Artificial Intelligence and Cyber Security, with particular interest in secure intelligent systems, neural cryptography, information security and emerging technologies.


His work combines academic research, university teaching, technical development and applied cybersecurity research, with an emphasis on responsible and secure adoption of emerging technologies.

Research Projects

Selected research and technical development projects.

AEGIS-SENTINEL

A research-oriented system for civilian airspace threat detection and critical infrastructure protection. The project explores sensor fusion, intelligent threat assessment and human-authorised decision making.

AI • Cyber Security • Sensor Fusion

AFSS

Research into secure and adaptive systems, optimisation, computational modelling and security-oriented system design. The project investigates computational approaches to complex security and optimisation problems.

Optimisation • Security • Computational Modelling

Cyber Web Assessment Agent

A modular web security assessment framework designed to collect evidence, analyse security characteristics, evaluate risk and produce structured assessment results.

Web Security • Automation • Risk Analysis
