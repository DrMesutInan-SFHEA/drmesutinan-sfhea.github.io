About

I am Dr Mesut İnan, PhD, SFHEA, a Cyber Security Researcher and Senior Lecturer working across Cyber Security, Artificial Intelligence and Computer Science.


My academic and research interests focus on the development, analysis and application of intelligent and secure computing systems, with particular emphasis on AI for Cybersecurity, Neural Cryptography, Information Security and secure software engineering.


My work combines academic research, practical technology development and higher education teaching.

Research Projects

Cybersecurity · AI · Critical Infrastructure

AEGIS-SENTINEL

An intelligent threat detection and assessment framework designed for civilian airspace and critical infrastructure protection.

The project combines sensor fusion, intelligent threat assessment and human-authorised decision making to support security-critical environments.

Research Focus: Sensor Fusion · Threat Detection · AI Security · Critical Infrastructure · Human-in-the-Loop Security
Cybersecurity · Optimisation · Secure Systems

A research framework investigating secure and adaptive system design through computational modelling and optimisation.

Cyber Web Assessment Agent

A modular automated web security assessment framework designed to collect technical evidence, analyse security weaknesses, evaluate risk and generate structured reports.

The architecture follows a modular assessment pipeline covering evidence collection, security analysis, risk evaluation and automated reporting.
